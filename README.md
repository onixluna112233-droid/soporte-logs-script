# Soporte Logs Script 🚀

Este proyecto contiene un script en Python diseñado para analizar archivos de logs de soporte técnico y detectar anomalías o eventos críticos de forma automática.

## 🛠️ Tecnologías utilizadas
* **Python 3.15**

## 📋 Funcionalidades
* Lectura y procesamiento de registros de log.
* Identificación automática de alertas como uso elevado de memoria RAM y errores de conexión (ej. timeouts en API de pagos o respuestas HTTP 500).
* Generación de un resumen rápido con el total de eventos críticos encontrados.

## 🚀 Cómo ejecutar el proyecto
1. Clona o descarga este repositorio.
2. Abre tu terminal de Git Bash dentro de la carpeta del proyecto.
3. Ejecuta el archivo con el siguiente comando:

```bash
python analizador.py
